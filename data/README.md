# Data record — provenance

The website renders from these committed files first (no live API needed) and
only re-checks the source in the background for newer data.

## `curated-extra.js` — 30 curated snapshots
- Generated by `scripts/build-curated-extra.py` (run it, commit the output).
  Values are rounded approximations: coffee (ICO 2023), tea (FAOSTAT/industry
  2022), beer (Kirin Beer University 2023 data), wine (OIV 2023), living
  languages (Ethnologue 27th ed. 2024), mean temperature (World Bank CCKP
  1991–2020 normals), bird/amphibian/reptile richness (IUCN Red List),
  Holocene volcanoes (Smithsonian GVP), time zones incl. territories (IANA),
  driving side (WorldStandards), landlocked status incl. doubly-landlocked
  Liechtenstein & Uzbekistan (UN-OHRLLS) — plus Nobel laureates
  (nobelprize.org), Olympic medals + per-capita (Olympedia, per-capita
  computed in the script from WB 2024 population), UNESCO sites (WHC),
  democracy status (Freedom House), legal systems (JuriGlobe), plug types
  and metric adoption (WorldStandards), EU/NATO/BRICS/OPEC/G20 membership,
  dominant language families (Ethnologue), government type (CIA Factbook),
  coffee production (FAO) and chocolate consumption (industry reports).
  Zero-default maps (Nobel, Olympics, UNESCO, blocs, coffee production…)
  treat missing-from-list as a real 0; the rest omit unknowns (hatched grey
  — never invented).

## `points.js` — static dot layers
- Generated by `scripts/build-points.py`: iconic eruptions (GVP VEI),
  megacities (UN WUP, metro pop), busiest airports (ACI 2023 pax),
  famous meteorites (Meteoritical Society). Coords approximate; fine at
  world-map scale.

## `earthquakes.json` — M6.0+ earthquakes since 2000 (USGS, public domain)
- Built by `scripts/build-earthquakes.py` from the ANSS ComCat FDSN API.
  Compact per-event records: id, time, magnitude, lon/lat, depth, place.
  Same stale-while-revalidate pattern as the WB data: render from the file,
   then query USGS for events newer than the snapshot and merge them in
   (browser copy in `localStorage` under key `mm-pt3-earthquakes`).

## `wb/*.json` — World Bank record
- Source: World Bank, World Development Indicators (CC-BY 4.0).
- Built from the official bulk download `WDI_CSV.zip`
  (databankfiles.worldbank.org) with `scripts/build-snapshot-from-wdi.py`.
  Aggregates (World, EU, income groups — rows with no Region in
  `WDICountry.csv`, 48 codes) are excluded; 213–217 real economies per dataset.
  The same 48-code blocklist is enforced in `app.js` and `fetch-data.mjs`
  because live API rows can't be trusted for region info — without it,
  aggregates like OED (OECD members) leak into rankings.
- Refresh from the API instead: `node scripts/fetch-data.mjs`
  (paginated, aggregate-filtered, and it refuses to write a snapshot where
  Argentina/Australia/India are missing).
- `wb/manifest.json` records fetch date, coverage and Argentina/Australia
  sample values per dataset, so a truncated download cannot slip through.
- Browser behaviour: render from `wb/<dataset>.json` → background check of
  api.worldbank.org → if newer, update in place and keep the refreshed copy
  in `localStorage` (`mm-wb3-<dataset>`). A static site cannot write back to
  this repo; maintainers re-run a refresh script and commit.

## `world.geo.json` — world boundaries, India as per Govt. of India
- Base: Natural Earth via johan/world.geo.json (vendored, 180 features —
  Argentina `ARG`, Australia `AUS`, India `IND` all present).
- India's geometry is **replaced** with the Survey-of-India-aligned official
  outline (full Jammu & Kashmir incl. PoK/Gilgit-Baltistan, Ladakh incl.
  Aksai Chin, Arunachal Pradesh; bbox reaches 37.08°N, vs ~35.5°N for the
  truncated de-facto outline), dissolved from `india-states-official.geojson`
  by `scripts/build-india-world.py` (build-time only, needs `shapely`).
- The app also draws India last so the official outline is not painted over
  by neighbouring de-facto polygons.
- Rendering note: the builder forces D3-spherical ring winding and cleans the
  dissolve (see `scripts/build-india-world.py`). It also fixes Bermuda in the
  base file, whose reversed ring made D3 paint the whole sphere — i.e. the
  "ocean" — in Bermuda's data colour. The app draws the ocean separately in
  one fixed colour (`#bfe0ee`) that no dataset can change.

## `india-states-official.geojson`
- India states/UTs with correct boundaries (MIT,
  AbhinavSwami28/india-official-geojson; J&K/Ladakh from
  india-in-data/kashmir, base states from Subhash9325/GeoJson-Data-of-Indian-States).
- Build-time input only: dissolved into the official India outline in
  `world.geo.json` by `scripts/build-india-world.py`. Always verify against
  the latest Survey of India publications for legal/official use.
