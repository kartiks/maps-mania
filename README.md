# 🌍 Maps Mania
Interactive world maps and dot layers: population, GDP, CO₂, coffee, Nobel laureates, Olympic medals, languages, birds, earthquakes, volcanoes, time zones, driving side, highest peaks, lakes, nuclear power & more — with timelines (77 datasets).

## Run
No build step. Serve statically (required — browsers block local data files over `file://`):
```bash
python3 -m http.server 8000
# open http://localhost:8000
```

## How data works (saved record + background update)
1. The map renders **immediately from the committed record** in `data/wb/*.json`
   (World Bank WDI, built from the official bulk download — see `data/README.md`).
   It works offline and can never show a half-downloaded country list.
2. In the background the app re-checks `api.worldbank.org` (fully paginated,
   aggregates excluded, Argentina/Australia/India presence-validated). If the
   API has newer data, the map updates in place and keeps the refreshed copy in
   `localStorage`; the status line under the map title tells you which happened.
3. Maintainers refresh the committed record with `node scripts/fetch-data.mjs`
   (or `python3 scripts/build-snapshot-from-wdi.py WDI_CSV.zip`) and commit `data/wb/`.

## Map boundaries
- World: Natural Earth, vendored in `data/world.geo.json` (180 countries incl.
  Argentina & Australia). The ocean is drawn once in a fixed colour (`#bfe0ee`)
  and is never recoloured by data; "no data" is a hatched grey, distinct from both.
- **India is depicted as per the Government of India / Survey of India**:
  full J&K (incl. PoK/Gilgit-Baltistan), Ladakh (incl. Aksai Chin), Arunachal —
  dissolved from `data/india-states-official.geojson` by `scripts/build-india-world.py`.

## Timelines
Datasets with a time series show the year slider + Play (Play stops at the
latest year; scrubbing pauses it; ⏭ jumps to latest). Single-year snapshots
hide the slider entirely and show a "Timeline unavailable" notice instead.

## Files
- `index.html` — structure, explorer, sources
- `style.css` — design
- `data.js` — curated country snapshots (median age, peaks, lakes, mammals, …)
- `data/curated-extra.js` — 30 curated snapshots (coffee → chocolate), generated by `scripts/build-curated-extra.py`
- `data/points.js` — dot layers (eruptions, megacities, airports, meteorites), generated by `scripts/build-points.py`
- `data/earthquakes.json` — M6+ quakes snapshot, generated by `scripts/build-earthquakes.py`
- `app.js` — D3 choropleth + dot layers, globe toggle (local record + stale-while-revalidate), timeline, rankings, spotlight
- `themes/theme-abyss.css` — the site's Deep Ocean Glass look (loaded on top of the base styles)
- `data/` — saved data record & boundaries (provenance: `data/README.md`)
- `scripts/` — `fetch-data.mjs` (API refresh), `build-snapshot-from-wdi.py` (bulk refresh), `build-curated-extra.py`, `build-points.py`, `build-earthquakes.py`, `build-india-world.py` (official India outline)
